# Thesis results

The results of the thesis, one folder per analysis in scientific order. They are the output of `reproduce_thesis_results`: a new run of the code writes exactly this layout into `runs/<run name>/`, so a rerun can be compared with these files one by one. Each analysis folder holds `figures/`, `tables/` (CSV), `data/` (the numerical results the figures and tables are computed from) and a `README.md` with the index of its figures and tables: title, what each shows, its scope and the command that re-renders it.

## Certified and healthy-fallback cells

The inversion-based analyses (fixed `04`-`07`, generalized `06`: the confirmation) show every cell with a selected provider: the certified cells (two independent AIES ensembles that agree) and the healthy fallbacks (a healthy provider that was not certified). The index of each analysis names, for every output, the cells it shows and which of them are healthy fallbacks or unavailable; a figure of one case gives its status in the title; the status of every cell is in `fixed/04_inversion/tables/cell_status.csv` and `fixed/07_conditional_inversion/tables/cell_status.csv`. Aggregates over cases count certified and fallback cells and state their number; summary tables give next to each value its value over the certified cells alone (columns ending in `_certified_only`). Unavailable cells have no posterior: they stay blank (grey in heatmaps) and are never shown as zero.

## Posterior draws

`fixed/04_inversion/data/draws/` (277 canonical cells) and `fixed/07_conditional_inversion/data/draws/` (160 conditional cells) hold, for every cell with a selected provider (certified, or a healthy fallback), every retained draw of both replicates of the provider's level at full precision: one file per cell, in the format a run of the code writes, with `index.csv`. Each file names the provider replicate and keeps, for each replicate, its saved health record and request, and for a certified cell its certification record. The files of 9 healthy fallbacks hold the provider only, because their second replicate did not finish (the reason is in the file). The draws are those of the thesis runs, unchanged; nothing is thinned or subsampled. Replicates are never pooled: the analyses read the provider, and the replicate-agreement analyses read both. In a rerun (`'Mode','rerun'`), `recovery` and `design_study` compute from these draws when the run has no inversion of its own.

The case folders `fixed/cases/case_<CaseID>/inversion/figures/` hold the corner plots of the thesis (gp_only, all six outputs, the canonical cases; settings A.10). `'CornerGallery','all'` draws the corner plot of every available cell (277 plots) from all retained draws of its provider.

## How these results were produced

- **Thesis and code:** *Surrogate Modelling and Bayesian Inference for Skin Characterization from Suction Experiments*, MSc thesis, ETH Zurich, 2026; the code and these results: <https://github.com/erionloni/skin_characterization_surrogate_modelling_bayesian_inference>.
- **Settings:** `study_settings.m`, the one settings file of both routes; its values are the thesis values.
- **`data/`:** the results of the thesis runs. The fixed-route surrogates and inversions ran on a computing cluster with MATLAB R2024a, the approved generalized surrogates and the best fit of the GP-mean inversion on a workstation with MATLAB R2025b, all with UQLab 2.3.0.
- **`figures/`, `tables/` and the READMEs:** rendered from `data/` in reproduce mode by `run_fixed_study`, `run_generalized_study` on 2026-10-17 with MATLAB 25.2.0.3177638 (R2025b) Update 5; rendering needs no UQLab.
- **Rendered by `run_fixed_study` with the steps recovery, combinations, conditional_inversion only** on 2026-11-07 with MATLAB 25.2.0.3177638 (R2025b) Update 5: the analyses of these steps and this index; rendering needs no UQLab.

## Regenerating

```matlab
reproduce_thesis_results                  % every figure and table, from data/ only, into runs/thesis_<time>/
run_fixed_study('Steps',{'sensitivity'})  % one analysis
run_fixed_study('Steps',{'inversion'},'CornerGallery','all')  % corner plot of every inversion cell
```

Reproducing needs neither UQLab nor any fitting, sampling or Fisher-information computation. Recomputing (`'Mode','rerun'`) is described in `docs/GUIDE.md`.
