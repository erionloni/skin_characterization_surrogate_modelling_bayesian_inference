# Fixed route: sensitivity

Sobol indices (first, total, second order), interaction gaps, ratio-output Sobol indices and ARD importance of the six closing pressures with respect to the four material parameters, from the GP and the PCE; the Sobol indices of 26 derived features of the pressures (ratios, differences, levels, decline shape), ranked per parameter.

The GP Sobol indices are Monte Carlo estimates (50,000 samples per matrix, recorded seed) with an error visible in the values: first-order indices above their totals by up to 0.0025 and second-order indices from -0.004 to 0.008. Indices of that size are zero within their error. The tables keep the estimates as computed, negative values included; only the interaction gap, max(S_T - S_1, 0), sets a negative difference to 0. Second-order indices are read per output and never averaged over outputs. The PCE indices are analytic.

The derived features (the files starting with `features_`, step `feature_sensitivity`): the first- and total-order Sobol indices of the derived features of the six pressures in the feature catalog of the settings (0.7), from the GP mean, with the estimator, sample and seed of the ratio indices (the raw sample is drawn first, as the step sensitivity draws it). Families: F1 ratios (within a probe, between the probes q, double ratios R), F2 differences (mbar), F3 levels (geometric means), F4 decline shape (curvature s and drop ratios; exploratory). Log-linear features are used as log f, differences and drop ratios raw; a feature that the step sensitivity already computes keeps its raw definition and its indices there (`tables/features_registry.csv`: the definition, convention, status and physical hypothesis of each feature). F0 shows the primary indices of the six pressures. Every feature is a function of the same six pressures.

A total-order index is the share of a feature's variation that a parameter explains, interactions included, not the size of that variation: the effect size sqrt(ST x variance) gives the size in the feature's own units (log units read as relative change; mbar for differences). Neither says whether the parameter can be recovered from a measurement. The existing Sobol path gives no confidence intervals. A drop ratio whose denominator changes sign over the sample, or whose variance a few samples carry (settings 0.7), is UNSTABLE: reported, not ranked (in the thesis results: dropratio_D6). The rankings mark the features of the observation design physics_guided_full_rank_six (pcl3_D2_mbar, r31_D2, d21_D2, r31_D6, r21_D6; its fourth feature, pcl1_D2_mbar / pcl3_D6_mbar, has no catalog entry).

The double ratio R = R21 = (pcl2_D2_mbar / pcl1_D2_mbar) / (pcl2_D6_mbar / pcl1_D6_mbar). Under independent 8 % relative errors of the six pressures, SD(log R) = 2c = 16 %. Decision record: "WP5, 26 Sep 2026. No inverse test with the double ratio R. log R is a linear combination of the within-probe log-ratios (row 1 minus row 3 of the contrast matrix A). Any valid observation design containing R is informationally identical to ratios_only or all_six, or discards information. Appending R to an existing design double counts and has a singular covariance. R could only change inference under a noise model with cross-probe, cycle-dependent correlation. Such a model is outside the scope of this thesis; measuring the device's noise correlations is an outlook item. R is reported as a sensitivity result and as a reconstruction diagnostic in WP3." (WP3: the ratio-error curves, `fixed/08_ratio_error_curves`.)
